# Project ASCEND

Project ASCEND is my personal engineering operating system.

It is the system I use to grow from a software developer into a stronger engineer, technical leader, and long-term builder of reliable systems.

## Current Mission

Become a production-ready software engineer who can:

- design systems with clarity
- deliver work with consistency
- communicate well with teams and clients
- learn modern technologies with purpose
- lead when responsibility grows

## Current Stage

- Level: `0`
- Status: `Foundation`
- Focus: `Engineer mindset, learning system, and baseline assessment`

## What This Repository Contains

- `ASCEND_MASTER.md` - the overall rules and learning philosophy
- `ASCEND_PROFILE.md` - my current learner profile and strengths
- `ASCEND_CURRICULUM.md` - the roadmap of topics and phases
- `ASCEND_PROGRESS.md` - progress tracking and promotion status
- `CHANGELOG.md` - record of changes made to Project ASCEND
- `STATUS.md` - human-readable project status
- `docs/` - deeper working documents
- `levels/` - curriculum levels and lessons
- `projects/` - practice work and applied exercises
- `notes/` - lesson notes and reflections
- `reflections/` - weekly self-review entries
- `architecture/` - system design notes
- `resources/` - curated learning references
- `assessments/` - reviews, checkpoints, and evaluations

## Learning Philosophy

- Learn with intent, not randomness
- Build more than I consume
- Use writing to clarify thinking
- Let projects prove understanding
- Repeat lessons until the concept is solid
- Ask what the skill solves, not just how it works

## Working Rule

If a topic does not improve my real-world engineering ability, it does not belong in the current sprint.
