# Level 0 Assessment

## Pass Condition

Level 0 is passed when the following are complete:

- Engineer manifesto is written
- Learning workflow is defined
- Baseline profile is written
- Weekly progress tracker is active
- The learner can explain the ASCEND system in plain language

## Review Questions

1. Why does Project ASCEND exist?
2. What kind of engineer is Charles becoming?
3. What are the top risks to consistency?
4. What is the current learning workflow?
5. What comes after Level 0?

## Mentor Decision

- `PASS`
- `REVISE`
- `RETAKE`

## Rule

If the answers are vague, Level 0 is not done yet.

## How To Use This File

1. Answer the lesson questions in each lesson file under `Your Answers`.
2. Update the deliverable file named in each lesson.
3. Review the deliverable before asking to move to the next lesson.
4. Use this file only after Level 0 is fully written and ready for review.
