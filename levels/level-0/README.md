# Level 0 - Engineer Mindset

## Purpose

Level 0 is the foundation of Project ASCEND.

Before we focus on tools, frameworks, or production systems, we define what kind of engineer Charles wants to become and how learning will work.

## Outcome

By the end of Level 0, Charles should be able to:

- explain why he is building Project ASCEND
- describe the kind of engineer he wants to become
- follow a consistent learning workflow
- review his own progress honestly
- move into technical topics with structure

## Lessons

- `lesson-01-engineer-identity.md`
- `lesson-02-learning-system.md`
- `lesson-03-baseline-assessment.md`
- `assessment.md`

## Rule

No technical level begins until the foundation is stable.

## Standard Lesson Flow

Each lesson follows the same format:

1. Goal
2. Why this matters
3. Questions
4. Your Answers
5. Deliverable
6. Acceptance Criteria
7. Final Output
8. Notes

## How To Work

- Answer the questions in the lesson file under `Your Answers`
- Update the deliverable file listed in the lesson
- Keep the final version in the deliverable file
- Use the lesson file as the worksheet and reference
