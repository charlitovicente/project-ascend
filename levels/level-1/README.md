# Level 1 - Engineering Fundamentals

## Purpose

Level 1 builds the core technical habits that every engineer needs.

This is where we turn good intentions into practical engineering habits:

- version control
- debugging
- clean code
- problem decomposition
- documentation

## Outcome

By the end of Level 1, Charles should be able to:

- use Git with confidence
- explain basic engineering workflow clearly
- debug problems methodically
- write cleaner and more maintainable code
- document work in a way other people can follow

## Rule

Level 1 is about discipline, not speed.
