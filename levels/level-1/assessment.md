# Level 1 Assessment

## Pass Condition

Level 1 is passed when the following are complete:

- Git and version control concepts are understood
- Debugging process is explained clearly
- Clean code principles are described in practical terms
- Problem decomposition method is usable
- Documentation habits are defined

## Review Questions

1. How do I use Git in a professional way?
2. How do I debug without guessing?
3. What does clean code mean to me?
4. How do I break down hard problems?
5. How do I document work so it stays useful?

## Mentor Decision

- `PASS`
- `REVISE`
- `RETAKE`

## Rule

If the answers are vague, Level 1 is not done yet.
