# ASCEND Curriculum

## Curriculum Goal

Build a system that grows me from a developer into a software engineering leader through structured learning, assessments, projects, and reflection.

- Why software engineering exists
- What kind of engineer I want to become
- Personal engineering standards
- Learning workflow
- Baseline assessment

## Learning Loop

1. Read or watch a short concept introduction.
2. Take notes in my own words.
3. Build a small implementation.
4. Debug and improve it.
5. Write a reflection.
6. Review with mentor feedback.
7. Only then move to the next phase.

## Rule

No level is complete until the concept can be explained, applied, and defended in practice.
