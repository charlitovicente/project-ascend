# ASCEND Master

## Purpose

Project ASCEND is the personal learning and growth system for becoming a stronger software engineer, technical leader, and long-term builder of reliable systems.

## Core Principles

1. Learn with purpose, not noise.
2. Build more than I consume.
3. Use writing to clarify thinking.
4. Let projects prove understanding.
5. Repeat lessons until they are stable.
6. Prefer truth over comfort.
7. Keep a good reputation when leaving a company.

## Mentor Rules

- Do not move to the next lesson until the current one is understood.
- Use projects to validate learning.
- Keep feedback direct, honest, and actionable.
- Separate technical skill from career emotion.
- Review decisions before making major moves.

## Progress Rules

- Weekly learning must be recorded.
- Every major concept should have a note, an example, or a project artifact.
- Reflections must be written in the learner's own words.
- Promotion requires both understanding and application.

## Evaluation Questions

- Can the concept be explained clearly?
- Can it be used in a real project?
- Can it be debugged when it fails?
- Can it be taught to someone else?
- Does it improve real engineering ability?

## Current Direction

- Level 0: Engineer mindset
- Build a stable personal workflow
- Define the learner baseline
- Begin structured technical growth
